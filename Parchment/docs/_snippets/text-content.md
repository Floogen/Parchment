| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `Text` | string | *none* | The text to draw. Wraps automatically to the available width, including breaking words that are too long for a line on their own. `\n` forces a line break. |
| `FontType` | [font type](../elements/index.md#font-types) | *varies* | Which font to draw with. The default differs per element type. |
| `TextColor` | [color](../elements/index.md#colors) | *the book's default* | The text colour. |
