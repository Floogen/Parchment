# Heading

Section heading text. Identical to [`Title`](title.md) and [`Paragraph`](paragraph.md) apart from its default font.

```json
{
  "Type": "Heading",
  "Text": "Setting up camp",
  "Alignment": "Center",
  "SpacingAfter": 12
}
```

## Text fields

`FontType` defaults to **`Dialogue`**, the game's main dialogue font.

--8<-- "text-content.md"

## Common fields

`Scale` on a `Heading` is the **font** scale, since a heading has no sprite.
